Zwift unter Lutris

Lutris-Installer für die Windows-Version von Zwift unter Linux. Zwift läuft im Lutris-Runner wine mit dw-proton; ein System-Wine ist nicht nötig.

ZwiftStart.exe

Startprogramm im Zwift-Verzeichnis: prüft die Version gegen das Zwift-CDN und aktualisiert bei Bedarf, stellt beim ersten Start Vollbild ein und startet ZwiftApp.exe als Kindprozess des Zwift-Launchers. Nur so lädt das Spiel unter Wine und zeigt das Anmeldefenster.

ZwiftStart.exe [--update-only | --no-update]

Benötigt .NET Framework 4.x im Präfix (winetricks dotnet48). Der Lutris-Installer lädt die Datei aus dem GitHub-Release.
