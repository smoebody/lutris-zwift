Zwift on Linux with Lutris

A Lutris install script for the Windows version of Zwift. Zwift runs in the Lutris wine runner using dw-proton; no system Wine is required. The game starts in fullscreen and keeps itself up to date.

Download zwift-lutris.yml

How to install

  1. Download zwift-lutris.yml using the button above. If your browser shows the file as text instead of saving it, use “Save Page As…” and keep the name zwift-lutris.yml.

  2. Install Lutris (version 0.5.22 or newer) from your distribution’s package manager:

    sudo dnf install lutris      # Fedora
sudo apt install lutris      # Debian, Ubuntu
sudo pacman -S lutris        # Arch Linux

    The Flatpak version of Lutris is currently not supported (see Troubleshooting).

  3. Open the local install script. In Lutris click + (top left), choose Install from a local install script (“Run a YAML install script”; German: “Installiere von einem lokalen Installationsskript”) and select the downloaded zwift-lutris.yml.

  4. Run the installation. Choose a new, empty directory as target, e.g. ~/Games/zwift, and click Install. Lutris first downloads dw-proton and the Steam runtime if they are missing, then installs .NET Framework 4.8, WebView2, the Zwift launcher and finally the game itself. This takes about 15–60 minutes depending on your connection; windows may pop up and close again. Do not cancel the installation.

    Afterwards start Zwift from Lutris (listed under Wine). Log in directly in the game window.

Disk space

Plan for about 12 GB of free space, better 15 GB, since updates need temporary space:

PartSizeLocation
Zwift with Wine prefixapprox. 9 GBchosen target directory
dw-protonapprox. 1.6 GB~/.local/share/lutris/runners/wine/
Steam runtime (umu)approx. 1.5 GB~/.local/share/umu/

dw-proton and the Steam runtime are shared with other Lutris games and only downloaded once.

Troubleshooting

SymptomCause and solution
Installation stops after a few seconds with “Command exited with code 256”; the log shows “wine client error: version mismatch”Flatpak Lutris, or a Lutris older than 0.5.22. The script expects dw-proton under ~/.local/share/lutris/runners/wine/. Install Lutris from your distribution’s packages.
Installation or update aborts, “No space left on device”Not enough disk space. Free at least 12 GB, then delete the target directory and start again.
Installation seems to hangInstalling .NET Framework 4.8 alone takes several minutes, the game download several GB. Wait; check network activity.
Download error, or checksum error for ZwiftStart.exeNo internet access, or a firewall/proxy blocks cdn.zwift.com or github.com. A checksum error means a broken download or an outdated script: download zwift-lutris.yml again.
Installation fails at “Download the game via the Zwift launcher”The game download took longer than 60 minutes or the launcher quit. Details are in drive_c/Program Files (x86)/Zwift/ZwiftStart.log inside the target directory. Simply start Zwift from Lutris: the update is resumed on every start.
Strange errors after installing into an existing directoryAlways install into a new, empty directory. Do not reuse a Wine prefix created with another Wine or Proton version.
Zwift closes right after startingSee ZwiftStart.log (path above) and drive_c/users/steamuser/AppData/Local/Zwift/Logs/Log.txt. Run Lutris from a terminal (lutris -d) for more output.
Black screen or graphics errorsMissing Vulkan drivers. Install the Mesa Vulkan drivers (e.g. mesa-vulkan-drivers, vulkan-radeon, vulkan-intel) or the NVIDIA driver including 32-bit libraries.
Window instead of fullscreen, or the other way roundFullscreen is set once as default. Change it in the Zwift settings; your choice is kept.
LoginLog in only in the Zwift game window. No credentials or tokens are stored by this project.

ZwiftStart.exe

Small launcher placed in the Zwift directory and used as the game executable. On every start it checks the installed version against the Zwift CDN and updates if needed, sets fullscreen as default on first start and starts ZwiftApp.exe as a child process of the Zwift launcher – only then does the game load under Wine and show the login window.

ZwiftStart.exe [--update-only | --no-update]

Requires .NET Framework 4.x in the prefix. The install script downloads it from the GitHub release automatically; the downloads below are for manual installations.
